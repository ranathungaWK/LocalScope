## Project Overview

LocalScope is a **locally installed developer tool with a web-based interface** that helps developers understand and diagnose problems in their local development environment.

Modern applications depend on multiple services such as frontends, backends, databases, caches, containers, and ML services. When something breaks, the visible error is often only a symptom of another change.

LocalScope monitors the local environment, tracks important changes, and correlates them with application behavior to help developers understand **what changed and what happened afterward**.

---

## Features

* 🔍 **Environment Monitoring** — Monitor processes, services, ports, containers, and system resources.
* 📦 **Project & Service Discovery** — Discover projects and the services running within them.
* 🩺 **Service Health Monitoring** — Track the health and availability of local services.
* 🔌 **Port Monitoring** — Detect port usage and conflicts.
* 🕒 **Event Timeline** — Track and review environment changes over time.
* 🧩 **Dependency Mapping** — Visualize relationships between services.
* 🧠 **Diagnostic Engine** — Identify possible causes by correlating events and dependencies.
* 📸 **Environment Snapshots** — Save known working environment states.
* 🔄 **Environment Comparison** — Compare the current environment with previous snapshots.
* 📊 **Application & Resource Insights** — Monitor application activity and system resources.
* 🌐 **Local Web Dashboard** — View the entire development environment from one place.
